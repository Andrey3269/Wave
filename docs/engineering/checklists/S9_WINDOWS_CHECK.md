# S9 — ручная проверка на Windows 11 (WebView2)

Чек-лист владельца для приёмки S9; результат зафиксирован 2026-10-16. S9 не меняет ни внешний вид, ни поведение (кроме M11 и
сигнала «пропуск», см. отчёт), поэтому проверка — «всё работает как в S8» плюс две целевые проверки.

Автоматические проверки этого не заменяют: CI собирает приложение и прогоняет e2e против установленного
`Wave.exe`, но в **Chromium из Playwright**, а не в окне **WebView2**. Главное, что видно только здесь, —
загружаются ли ES-модули интерфейса в WebView2 вашей системы.

**Сборка.** Ветка `claude/s9-app-js-modules`, `build_windows.bat` (или установщик из артефакта CI). Версия
приложения не менялась (0.1.0) — установщик ставится поверх как обновление. Перед началом: закрыть Wave,
сохранить копию `%LOCALAPPDATA%\Wave`.

| № | Проверка | Ожидаемо | Результат |
|---|---|---|---|
| 1 | Установить сборку S9 поверх установленной Wave и запустить | окно открывается **с интерфейсом** (не пустое, не белое); главная, баннер, миксы, лента на месте; прежние избранное, история, плейлисты, настройки, громкость сохранились; интерфейс появляется **не заметно медленнее, чем в S8** (в Linux Chromium модули добавили ~0,13 с к холодному старту — отчёт §6) | **PASS** (владелец, 2026-10-16) |
| 2 | Если доступны средства разработчика WebView2 (F12 / правый клик «Проверить»): вкладка Console после запуска | нет ошибок вида «Failed to load module script», «MIME type», «does not provide an export named» | **PASS** (владелец, 2026-10-16) |
| 3 | Там же, вкладка Network: файлы `js/main.js`, `js/core/…`, `js/views/…` | все с кодом 200 (или 304 при повторном запуске), тип `text/javascript`; запросов во внешнюю сеть за скриптами нет | **PASS** (владелец, 2026-10-16) |
| 4 | Пройти по всем пунктам меню: главная, поиск (треки, артисты, альбомы), артист, альбом, микс из боковой панели, «Коллекция», «Нравится», «Скачанные», история, плейлисты, настройки | каждый экран открывается, «Назад» возвращает на предыдущий | **PASS** (владелец, 2026-10-16) |
| 5 | Воспроизведение YouTube Music и SoundCloud: пауза, перемотка, следующий/предыдущий, громкость и mute, страница трека, полноэкранный плеер (обложка, текст, очередь) | как в S8 | **PASS** (владелец, 2026-10-16) |
| 6 | **M11.** Найти трек, запустить первую строку результатов. Открыть очередь (кнопка очереди в мини-плеере). Сменить сортировку списка (например, «По исполнителю»). Снова открыть очередь | порядок очереди **не изменился**; «Следующий» играет второй трек очереди, а не второй трек отсортированного списка | **PASS** (владелец, 2026-10-16) |
| 7 | На том же списке прокрутить вниз до подгрузки следующей страницы (если источник её отдаёт) и открыть очередь | новые треки добавились **в конец** очереди, прежний порядок сохранён | **PASS** (владелец, 2026-10-16) |
| 8 | Правки очереди: «Играть следующим», «Добавить в очередь», перетаскивание в полноэкранной очереди, «Убрать», «Очистить» | как в S8; список на экране от правок очереди не меняется | **PASS** (владелец, 2026-10-16) |
| 9 | Скачать трек, удалить загрузку; воспроизвести скачанный трек без сети | как в S5/S8 | **PASS** (владелец, 2026-10-16) |
| 10 | Изменить тему, имя профиля, громкость; закрыть и снова открыть Wave | значения сохранились | **PASS** (владелец, 2026-10-16) |
| 11 | Закрыть Wave, проверить диспетчер задач | процессов `Wave.exe` и `deno.exe` не осталось | **PASS** (владелец, 2026-10-16) |

Результат каждого пункта — PASS / FAIL / NOT RUN; для FAIL — что видно, снимок консоли WebView2 (п. 2) и
фрагмент `%LOCALAPPDATA%\Wave\logs\wave.log`.

## Результат

**PASS — 11/11 пунктов.** Владелец подтвердил прохождение всего чек-листа на Windows 11 с WebView2 2026-10-16. Результат записан по прямому подтверждению владельца.
