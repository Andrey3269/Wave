# S8 — ручная проверка на Windows 11 (WebView2)

Что проверяет владелец на своей машине перед решением о приёмке S8. Автоматические проверки CI
(`windows-latest`: сборка, установщик, e2e против установленного `Wave.exe` в Chromium) этих пунктов
не заменяют: CI не запускает окно WebView2 и не ходит в настоящий SoundCloud.

**Сборка.** Ветка `claude/s8-hls-playback`, `build_windows.bat` (или установщик из артефакта CI). Версия
приложения не менялась (0.1.0), поэтому установщик ставится поверх текущей Wave как обновление.

**Как найти HLS-only трек SoundCloud.** SoundCloud сам решает, отдать ли прогрессивный mp3: у одного и того же
трека набор форматов меняется от запроса к запросу (N4). В облачной проверке 2026-10-14 трек
`343609555` (из `tests/live_targets.json`) в половине резолвов был только AAC-HLS. В журнале
`%LOCALAPPDATA%\Wave\logs\wave.log` каждый резолв помечен видом потока:
`Резолв sc:… занял 2.1 с (hls, aac)` или `(progressive, mp3)`. Если трек сыграл как progressive,
«Очистить кэш» в настройках и запустить его снова — до записи `hls`.

Перед началом: закрыть Wave, сохранить копию `%LOCALAPPDATA%\Wave` (база, журнал) — на случай разбора.

| 5 | На HLS-треке: пауза и продолжение с того же места; перемотка вперёд (в последнюю треть) и назад; клик по шкале | звук продолжается с нужного места без долгих пауз | |

| 11 | Отключить сеть, воспроизвести скачанные треки (п. 9 и 10), перемотать | играют с диска, перемотка работает | |
| 12 | Старые загрузки (до S8) | на месте, играют | |
| 13 | Открыть средства разработчика WebView2 (если доступны) и проиграть HLS-трек, переключить треки | в консоли нет ошибок; на вкладке сети нет запросов к CDN за `hls.light.min.js` — он грузится с `127.0.0.1` | |
| 14 | Закрыть Wave во время HLS-трека, проверить диспетчер задач | процессов `Wave.exe` и `deno.exe` не осталось | |
| 15 | Повторный запуск после закрытия | всё работает, HLS-трек играет снова | |

Результат каждого пункта — PASS / FAIL / NOT RUN; для FAIL — что видно и фрагмент `wave.log` (в журнал не
пишутся ссылки и подписи CDN).
