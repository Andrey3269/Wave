# S11 — ручная проверка на Windows 11 (WebView2): загрузки, отмена, очередь, очистка (WIN-14)

Ручной чек-лист владельца для приёмки S11. **Все пункты — NOT RUN до фактической проверки владельцем.**
WIN-14 нельзя считать пройденным по Linux-тестам или Windows CI: CI проверяет код на `windows-latest` (в том числе
настоящую NTFS-junction) и собирает установщик, но не открывает окно WebView2, не качает настоящие треки
YouTube Music и SoundCloud и не работает с вашими путями, OneDrive и сетевыми дисками.

**Сборка.** Ветка `claude/s11-downloads`, `build_windows.bat` (или установщик из артефакта CI `windows-build`).
Версия приложения не менялась (0.1.0) — установщик ставится поверх как обновление. Схема базы не менялась (v1).
Перед началом: закрыть Wave, сохранить копию `%LOCALAPPDATA%\Wave` и, на всякий случай, папки загрузок.

**Что поменялось для пользователя (для ориентира).**
- Одновременно идут **не больше двух загрузок**; третья и следующие показывают «В очереди» (приглушённый крестик,
  без процента) и начинаются сами, когда освободится место.
- Кнопка идущей загрузки **не блокируется**: на ней крестик и процент, нажатие **отменяет** загрузку (также из меню
  «⋯» → «Отменить загрузку»). После отмены — сообщение «Загрузка «…» отменена», кнопка снова «Скачать».
- Если отмена опоздала (трек уже сохраняется) — честное «уже сохранён — отменить не успели», кнопка «Скачано».
- При закрытии приложения недокачанные загрузки отменяются и их временные папки `… [yt-ID].part` удаляются;
  при следующем запуске остатки прошлых сбоев удаляются во всех папках загрузок, где Wave сохранял треки.
- «Скачанные»: строка состояния «Скачано: N · загружается: A · в очереди: Q».

**Подготовка путей (для пунктов 1–4).** Создайте папку с длинным путём и кириллицей, например
`C:\Users\<вы>\Music\Очень длинное название папки для проверки длинных путей Windows\Ещё один уровень вложенности с кириллицей\Волна загрузки`
(весь путь — 200+ символов; сама ВОЛНА добавляет к нему имя папки трека до ~130 символов). В «Настройках» Wave
укажите её как папку загрузок. Для треков выберите исполнителя или название с кириллицей.

| № | Проверка | Ожидаемо | Результат |

Для FAIL — что видно (снимок экрана), путь папки загрузок, содержимое папки (`dir /a`), снимок консоли WebView2
(F12 / «Проверить», если доступно) и фрагмент `%LOCALAPPDATA%\Wave\logs\wave.log` (в журнале есть строки
«Загрузка … отменена», «Удалено недокачанных загрузок», «Временная папка загрузки … не удалена»).

**Известные ограничения, которые этот чек-лист должен подтвердить или опровергнуть** (подробно — отчёт S11 §8):
- Windows: защита от подмены папки `.part` ссылкой во время удаления — повторная сверка каталога (на POSIX — через
  дескриптор каталога); на SMB/FAT номер файла бывает 0, тогда сверка ничего не даёт. Для этого нужен локальный
  процесс, специально подменяющий папки в каталоге загрузок.
- Если очистка при запуске «зависла» на недоступном сетевом диске, загрузка трека, чья старая `.part` лежит именно
  там, ждёт её в состоянии «Подготовка» (отмена работает).
