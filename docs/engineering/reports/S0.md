## 4. Оставшиеся ограничения

1. **Windows не проверялась.** Команды README для Windows, `build_windows.bat` с constraints и окно приложения требуют проверки на Windows 11 x64 (и по возможности 10 22H2). Автоматически это закроет CI в S1.
2. **Платформенные пакеты.** `constraints.txt` снят на Linux. Пакеты, которые ставятся только на Windows (например `colorama`), в нём не закреплены. Будет уточнено по результатам Windows-job в CI.
3. **Зависимости сборки** (PyInstaller, pywebview, Pillow) не закреплены. Это сознательно: закреплю после первой проверенной сборки на Windows (S3–S4).
4. **Версия Playwright 1.56.0** выбрана как проверенная с доступным Chromium 141. После `python -m playwright install chromium` на машине разработчика ставится браузер ровно под эту версию.
5. **Ограничения из аудита не исправлялись в этом этапе:**
   - H1 (JS-runtime для YouTube) — S3;
   - H2 (инсталлятор) — S4;
   - H3 (настройки) — S2a;
   - политика источников по ADR-5 и ADR-6 — S5. В текущем коде загрузки и SoundCloud ещё работают как раньше; это прямо указано в README.
6. **Шаг установщика** в `build_windows.bat` по-прежнему завершится ошибкой: файла `installer/wave.iss` нет (S4).
