Wave / «ВОЛНА» — уведомления о сторонних компонентах воспроизведения YouTube
===========================================================================

Этот файл и папка licenses/ поставляются вместе с приложением (в собранной папке:
_internal\licenses\). Здесь перечислены компоненты, которые этап S3 добавил или закрепил
в распространяемой сборке для воспроизведения YouTube. Полный перечень лицензий всех
компонентов сборки (Python, pywebview, pythonnet, FastAPI и др.) составляется на этапе S4
вместе с установщиком.


1. Deno 2.9.7 — JavaScript-runtime
-----------------------------------
Назначение: решение JS-задач плеера YouTube для yt-dlp. В сборке: runtime\deno\deno.exe.
Источник: официальный релиз https://github.com/denoland/deno/releases/tag/v2.9.7
          (deno-x86_64-pc-windows-msvc.zip, SHA-256 архива
          a0c3101b4158d1dfb7d6a78a7bf0f3de80c96bb423c152beec8beb22786f2238, сверен с официальным
          файлом .sha256sum релиза). Файл используется без изменений.
Лицензия: MIT, Copyright 2018-2026 the Deno authors. Полный текст: licenses\deno\LICENSE.md
          (из репозитория Deno, тег v2.9.7).
Исходный код: https://github.com/denoland/deno/tree/v2.9.7

В исполняемый файл Deno статически встроены движок V8 (версия 15.0.245.2) и библиотеки
на Rust. Текст лицензии V8 (BSD-3-Clause и лицензии встроенных в V8 библиотек):
licenses\v8\LICENSE (из репозитория V8, тег 15.0.245.2). Официальный архив Deno не содержит
сводного файла уведомлений для встроенных библиотек Rust; их перечень и лицензии определяются
по Cargo.lock исходного кода Deno v2.9.7. Состав этих уведомлений для публичного
распространения подлежит проверке на этапе S4.

Не входят в сборку
------------------
Пакеты из extra yt-dlp[default], которые Wave не использует, не устанавливаются и в сборку
не попадают, в том числе mutagen (GPL-2.0-or-later), pycryptodomex и brotli.
